# ТЗ — сайт-прототип строительной компании «NORDHAUS»
*(название рабочее, заменить можно одной константой `BRAND` в `config/site.ts`)*

Многостраничный сайт-прототип компании, которая строит каркасные загородные дома под ключ. Задача — **вау-эффект с первой секунды**, продающие тексты и премиальное ощущение. Это портфолио-кейс AlexWebStudio.

Стек: **Next.js 15 (App Router) + TypeScript + Tailwind CSS v4 + GSAP (ScrollTrigger, SplitText) + Lenis**. Деплой на Vercel.

## 2. Hero-блок (самое важное, делать первым и вылизывать)

Повторить композицию ARCHISTUDIO один в один, но в нашей светлой гамме, либо оставить hero тёмным как отдельную «сцену» (решение: **hero тёмный, графит `#16181B`**, остальной сайт светлый — создаёт контраст при скролле, переход сделать плавным).

**Композиция (desktop 1440px):**
- Одна большая фотография дома, **разрезанная на 4 вертикальные колонки** (одно изображение, видимое через 4 «окна»). Между окнами ровные зазоры ~12–16px цвета фона.
- **Колонки разной высоты и смещены по вертикали:** 1-я и 2-я короче (заканчиваются над логотипом), 3-я — самая длинная, уходит вниз до уровня подзаголовка, 4-я короче и чуть ниже по верхнему краю. Ритм «ступенек», как в референсе.
- Скругления окон большие: **~28px**. Тонкий светлый stroke 1px `rgba(255,255,255,.12)`.
- Фото одно на все окна: реализовать через `background-attachment`-подобный приём — каждое окно с `overflow:hidden`, внутри одна и та же картинка с `object-position`, рассчитанным от левого края контейнера (или CSS `background-size` на ширину всего hero + `background-position-x` со смещением колонки). Картинка должна читаться как единая.
- **Логотип** снизу слева поверх нижней части колонок 1–2: огромный, широкий, капсом, белый, ~11vw. Под ним подзаголовок серым в 2 строки.
- **Справа** от 3-й колонки, под 4-й — стопка из 4 слов капсом, выравнивание вправо, чередование яркости (белый / серый / белый / серый): `КАРКАС / ТЕПЛО / 60 ДНЕЙ / НАВСЕГДА` (или аналог).
- Хедер поверх фото: лого-иконка слева, меню в центре (активный пункт — пилюля с обводкой), переключатель RU/KZ пилюлями, справа белая пилюля-кнопка «ОБСУДИТЬ ПРОЕКТ».

**Анимация входа (после прелоадера):**
1. Окна «вырастают» по очереди снизу вверх через `clip-path: inset(100% 0 0 0 round 28px)` → `inset(0 round 28px)`, stagger 0.12s, ease `expo.out`, 1.4s.
2. Внутри окон фото слегка масштабируется 1.15 → 1.
3. Логотип — эффект **Text Flip** (буквы переворачиваются по X поочерёдно).
4. Стопка слов справа и подзаголовок — **Blur In**.
5. На скролле: колонки параллаксят с разной скоростью (1 и 3 быстрее, 2 и 4 медленнее), логотип уходит вверх медленнее контента.

**Мобилка:** 2 колонки вместо 4 (разной высоты), логотип на всю ширину, слова справа переезжают под подзаголовок в строку.

## 3. Дизайн-система

### Цвета (из референса «каркасный дом»)
```
--bg:          #EEEFF1   /* основной светлый серый фон */
--surface:     #F7F7F8   /* светлые карточки */
--glass:       rgba(255,255,255,.55) + backdrop-blur(20px)
--dark:        #1E2024   /* тёмные карточки, кнопки */
--dark-2:      #2A2D32   /* градиент тёмных карточек */
--graphite:    #16181B   /* hero */
--text:        #141518
--muted:       #7A7E86
--line:        rgba(20,21,24,.08)
--wood:        #B07A4F   /* акцент дерева — точечно: цифры, hover, иконки */
```
Ощущение: серый бетон + графит + тёплое дерево. Никаких фиолетовых градиентов и неона.

### Шрифты
- **Display (как ARCHISTUDIO)** — `Unbounded` 600/700, капс. Использовать: логотип, меню, hero, заголовки карточек каталога, крупные цифры. Альтернатива для проверки: `Gilroy ExtraBold` если есть лицензия.
- **Основной (как ЭСТ)** — `Onest` (или `Inter Tight`) 400/500. Заголовки секций 500, крупно, плотный трекинг `-0.02em`, межстрочный 1.05. Описания 400, `--muted`.
- Микро-лейблы секций — 12px, капс, пилюля с обводкой (как «О НАС» в ARCHISTUDIO и «ПОЧЕМУ НАС ВЫБИРАЮТ» в ЭСТ).

### Формы
- Радиусы: секции-контейнеры **32px**, карточки **24px**, фото в карточках **20px**, кнопки — пилюли `999px`.
- Секции «плавают» на фоне как отдельные скруглённые панели (как в референсе каркасного дома), отступ от краёв 16–24px.
- Кнопки: тёмная пилюля + круглый кружок со стрелкой справа (ЭСТ). На hover кружок сдвигается/стрелка проворачивается.
- **Стеклянные карточки** (glassmorphism): фон `--glass`, `backdrop-filter: blur(20px) saturate(140%)`, обводка 1px `rgba(255,255,255,.6)`, внутренний верхний блик `inset 0 1px 0 rgba(255,255,255,.7)`, мягкая тень `0 20px 60px -20px rgba(0,0,0,.15)`. Использовать: статистика в hero второго экрана, бейджи поверх фото, плашки в каталоге, шаги квиза.

## 4. Анимации и эффекты

1. **Прелоадер** — свой, не копировать с alexwebstudio.ru (там можно только посмотреть уровень). Концепция: на графитовом фоне тонкими линиями рисуется **каркас дома** (SVG stroke-dashoffset — стойки, балки, стропила), счётчик 0→100% шрифтом Unbounded, затем каркас «заполняется» и экран уезжает вверх с `clip-path`, открывая hero, где сразу стартует анимация окон. Длительность ≤ 2.2s, при повторном визите в сессии — укороченная версия 0.6s.
2. **Плавный скролл** — Lenis (`lerp: 0.09`), синхронизация с GSAP ScrollTrigger через `gsap.ticker`.
3. **Text Flip** — эффект с https://aw-flow.alexwebstudio.ru/effects/text-flip (изучить код/поведение страницы и воспроизвести как React-компонент `<TextFlip>`). Применять: логотип в hero, H2 ключевых секций.
4. **Blur In** — эффект с https://aw-flow.alexwebstudio.ru/effects/blur-in (`<BlurIn>`). Применять: подзаголовки, абзацы, слова-стопка в hero, карточки.
5. Другие эффекты с моего сайта **не брать**.
6. Дополнительно можно брать готовые компоненты с 21st.dev, Aceternity UI, Magic UI, ReactBits и адаптировать под стиль: magnetic-кнопки, счётчики цифр, marquee логотипов партнёров/банков, image reveal, tilt карточек каталога, стеклянный хедер.
7. Скролл-моменты:
   - Секция «Технология»: SVG-каркас дома прорисовывается по скроллу (scrub), рядом выезжают 3 тёмные карточки преимуществ.
   - Каталог: горизонтальный слайдер с drag + стрелки-кружки, фото при hover зумится, плашка с ценой — стекло.
   - «3 шага»: pin-секция, цифры [1] [2] [3] переключаются по скроллу, прогресс-линия.
   - Цифры статистики — count-up при появлении.
8. `prefers-reduced-motion` — отключить параллакс/flip, оставить fade.

## 5. Структура сайта (многостраничный)

### `/` Главная
1. **Hero** (ARCHISTUDIO, см. п.2)
2. **Оффер + статистика** — «Каркасный дом от 100 м² под ключ за 60 дней». 3 стеклянные карточки: `65 дней средний срок`, `7 лет гарантии`, `180+ домов с 2013`. Кнопка «Рассчитать стоимость» (открывает квиз).
3. **Почему мы** (ЭСТ) — 4 карточки с иконкой, текстом и крупной цифрой: качество / индивидуальный проект / 0 срывов сроков / сопровождение 24/7.
4. **Технология** — «Строим по каркасной технологии», SVG-каркас + 3 тёмные карточки: прочность, теплоизоляция, отсутствие усадки. Ссылка на `/technology`.
5. **Каталог проектов 2026** — 4–8 карточек: фото, название (Unbounded), м², спальни, цена «от ... ₸». Кнопка «В каталог».
6. **Способы оплаты** — 4 карточки (чередование светлая/тёмная, как в референсе): ипотека/кредит, рассрочка от застройщика, господдержка/программы, безнал для юрлиц. Каждая ведёт на свою страницу.
7. **3 шага до нового дома** — консультация и проект → строительство → отделка и ключи.
8. **Реализованные объекты** (ЭСТ «Дома, в которых начинается ваша история») — 3 карточки + «Смотреть все».
9. **Отзывы** — стеклянные карточки, фото семьи, город, срок стройки (тексты-заглушки помечены как демо).
10. **FAQ** — аккордеон, 6–8 вопросов (зима, фундамент, отопление, гарантия, сроки, документы).
11. **Финальный CTA** (ЭСТ) — тёмный баннер с вечерним фото дома: «Построим дом вашей мечты — качественно и в срок» + кнопка квиза.
12. **Футер** — лого, меню, контакты, соцсети, кнопка «наверх».

### Остальные страницы
- `/catalog` — фильтры (площадь, этажность, спальни, бюджет), сетка карточек.
- `/catalog/[slug]` — страница проекта: галерея, планировки, характеристики, комплектации (Тёплый контур / Под чистовую / Под ключ), смета «от», CTA.
- `/technology` — подробно про каркас: слои стены (интерактивный «разрез» с подписями), сравнение с газоблоком/кирпичом таблицей.
- `/projects` — реализованные дома с фото «до/после» (слайдер-сравнение).
- `/payment/mortgage`, `/payment/installment`, `/payment/subsidy`, `/payment/cashless` — отдельная страница на каждый способ оплаты: условия, калькулятор платежа, шаги, CTA.
- `/about` — о компании, цифры, команда, производство.
- `/contacts` — карта, контакты, форма.
- 404 — с юмором про «здесь фундамент ещё не залит».

## 6. Квиз «Обсудить проект» (вау-элемент №2)

Открывается **попапом** с любой CTA-кнопки. Попап не просто появляется: кнопка «Обсудить проект» морфится (FLIP-анимация) — разрастается в полноэкранную панель, фон сайта уходит в blur.

**Механика «Собери свой дом»:** слева пользователь отвечает на вопросы, **справа живое превью дома**, которое меняется от ответов (сменяется фото/рендер, растут цифры площади, бегущая цена «от ... ₸», срок стройки). Это главная фишка — человек видит, как «строит» дом.

Шаги (каждый — один экран, крупные стеклянные карточки-варианты с картинками, выбор в 1 клик, автопереход):
1. Для чего дом? (ПМЖ / дача / баня-гостевой / под сдачу)
2. Площадь — слайдер 60–250 м², превью дома растёт
3. Этажность (1 / 1.5 мансарда / 2)
4. Спальни (1–5)
5. Комплектация (тёплый контур / под чистовую / под ключ) — цена пересчитывается
6. Есть участок? (да / в процессе / нет — поможем подобрать)
7. Когда планируете начать? (в этом сезоне / через 3–6 мес / просто смотрю)
8. Способ оплаты (наличные / ипотека / рассрочка / господдержка)
9. **Финал:** «Ваш дом: 120 м², 2 этажа, 3 спальни — от 18 500 000 ₸, срок ~65 дней». Форма: имя + телефон (маска +7) + способ связи (WhatsApp / Telegram / звонок). Подарок за заявку: «Пришлём 3 готовых проекта под ваши параметры и смету в PDF».

Продающие элементы: прогресс-бар с текстом «осталось 2 вопроса», кнопка «назад», ответы сохраняются, бейдж «ответ займёт 40 секунд», социальное доказательство внизу («34 семьи рассчитали дом на этой неделе» — демо). Закрытие по Esc/клику мимо, фокус-трап, полная доступность с клавиатуры. На мобилке — fullscreen bottom-sheet, превью дома сверху компактно.

После отправки — экран успеха с анимацией (дом «собирается» из линий) и кнопкой в WhatsApp. Бэкенд не нужен: отправка в API route с заглушкой (console + TODO на Telegram-бота).

## 7. Тексты

Продающие, конкретные, без воды. Основа — тексты из трёх референсов, объединить и усилить: цифры, сроки, гарантии, снятие возражений (зима, «каркас — это несерьёзно», переплаты, срыв сроков). Тон — уверенный, коротко, «дерзко и резко». Валюта — тенге, регион — Казахстан (Караганда/Астана/Алматы). Все отзывы, цифры и цены пометить в коде как демо-данные (`data/*.ts`).

## 8. Фото

Пользователь положит набор фото в `public/images/raw`. Распределить по секциям. Если не хватает — составить список `IMAGES_NEEDED.md`: какая секция, что на фото, ракурс, время суток, пропорции, + готовый промпт для генерации нейронкой (стиль: фотореализм, современный каркасный дом, тёмный металл + дерево + панорамные окна, хвойный лес, мягкий дневной/вечерний свет). Обязательно нужно: одно широкое фото для hero (≥ 2400px, дом по центру, чтобы читался во всех 4 окнах).

## 9. Технические требования
- Lighthouse ≥ 90 (Performance), `next/image`, AVIF/WebP, lazy, шрифты через `next/font`.
- Адаптив: 360 / 768 / 1024 / 1440 / 1920.
- SEO: metadata на каждой странице, OG-картинки, sitemap, JSON-LD (HomeAndConstructionBusiness).
- Компоненты переиспользуемые, данные отдельно от разметки.
- Без бэкенда, всё статикой, деплой на Vercel.
